Atualização de Dados

Carregue um novo arquivo JSON ou Excel para atualizar o dashboard

📋 Como atualizar os dados automaticamente

  1. Preencha a planilha FATO_Lancamentos com os novos lançamentos
  2. Execute o script Python: python export_json.py (fornecido separadamente)
  3. O script gera o arquivo dashboard_data.json
  4. Clique no botão acima e selecione o dashboard_data.json gerado
  5. O dashboard será atualizado automaticamente

⚡ Atualização avançada (automática em rede)

  • Salve o dashboard_data.json em uma pasta compartilhada ou servidor web
  • Configure a URL no campo abaixo para atualização automática a cada 5 minutos
